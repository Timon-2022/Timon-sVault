# .claude 模板文件合集

> 复制这些内容到你的工作区，创建`.claude`文件即可使用

## 模板1：办公自动化

```markdown
# 项目：办公自动化工作区

## 项目目标
自动处理日常办公中的重复性任务，提升工作效率

## 工作规范
1. 文件命名：使用中文，格式为"项目_日期_内容.扩展名"
2. 输出格式：优先使用Markdown、PDF、Excel
3. 时间格式：YYYY-MM-DD HH:mm
4. 数字格式：保留2位小数（金额）

## 交互偏好
- 使用中文输出
- 代码需要详细注释
- 重要操作前先说明会做什么
- 复杂任务分步骤执行

## 质量标准
- 数据准确性优先于速度
- 文件格式规范统一
- 保留操作日志
```

## 模板2：工资表处理

```markdown
# 工资表处理项目配置

## 项目描述
每月处理公司工资总表，拆分为独立的员工工资条

## 输入格式
- Excel文件（.xlsx）
- 包含字段：姓名、部门、基本工资、绩效、扣款、实发工资

## 输出要求
1. 文件格式：PDF
2. 文件命名：{姓名}_{月份}_工资条.pdf
3. 示例：张三_2025-01_工资条.pdf

## 处理规则
1. 保留两位小数
2. 敏感字段（身份证号）部分隐藏
3. 按部门分类输出到不同文件夹
4. 生成处理汇总报告

## 保密要求
- 处理完成后删除临时文件
- 不在日志中记录具体工资数据
- 每次处理前确认操作环境安全

## 交互偏好
- 处理前显示处理预览
- 遇到异常数据暂停并询问
- 完成后生成处理报告
```

## 模板3：数据分析

```markdown
# 数据分析工作区配置

## 项目目标
快速分析各类业务数据，提取洞察并生成报告

## 分析标准
1. 数据质量检查：识别异常值、缺失值、重复值
2. 统计指标：均值、中位数、标准差、分位数
3. 趋势分析：同比、环比、移动平均
4. 关联分析：相关性、聚类、异常点

## 输出格式
### 分析报告结构
1. 数据概览（行数、列数、时间范围）
2. 关键发现（3-5个要点）
3. 详细分析（分维度展开）
4. 可视化建议（推荐图表类型）
5. 行动建议（基于数据）

### 图表推荐
- 趋势：折线图
- 对比：柱状图
- 占比：饼图
- 分布：直方图
- 相关：散点图

## 交互偏好
- 优先使用表格展示数据
- 关键结论用粗体标注
- 异常数据用⚠️标记
- 每个分析给出数据支撑

## 常见任务
- Top N分析
- 趋势识别
- 异常检测
- 对比分析
- 预测建议
```

## 模板4：内容创作

```markdown
# 内容创作工作区配置

## 创作目标
高效生成各类办公和营销内容

## 写作风格
1. 语言简洁明了，避免专业术语
2. 多用案例和比喻
3. 句子控制在20字以内
4. 段落不超过5行

## 内容类型
### 邮件写作
- 主题：明确、简洁
- 称呼：使用对方姓名
- 结构：问候→目的→详情→行动→结尾
- 语气：专业但不生硬

### 会议纪要
- 参会人员
- 讨论要点（分议题）
- 决策事项（结论+理由）
- 待办任务（任务+负责人+截止日期）

### 工作汇报
- 本周工作（3-5项）
- 关键成果（数据说话）
- 遇到问题（问题+影响）
- 下周计划（具体可执行）

## 质量标准
- 无错别字
- 逻辑清晰
- 数据准确
- 格式统一

## 优化要求
- 初稿完成后自动检查
- 标注需要人工审核的部分
- 提供多个版本供选择
```

## 模板5：文件管理

```markdown
# 文件管理工作区配置

## 管理目标
保持文件系统整洁有序，快速定位所需文件

## 文件分类规则
### 按类型分类
```
📁 图片/
  ├── PNG/
  ├── JPG/
  └── 其他/

📁 文档/
  ├── Word/
  ├── PDF/
  ├── Excel/
  └── PPT/

📁 软件/
  ├── Windows/
  └── Mac/

📁 压缩包/
  ├── ZIP/
  └── RAR/
```

### 按时间分类
```
📁 2025/
  ├── 2025-01/
  ├── 2025-02/
  └── ...
```

### 按项目分类
```
📁 项目A/
  ├── 需求文档/
  ├── 设计稿/
  ├── 会议记录/
  └── 交付物/
```

## 命名规范
- 日期：YYYY-MM-DD
- 版本：v1.0、v2.0
- 状态：草稿、审核中、终稿
- 示例：项目需求_20250130_v2.0_终稿.docx

## 操作规则
1. 新文件自动分类归档
2. 重复文件询问处理方式
3. 空文件夹清理提醒
4. 大文件（>100MB）特别标注

## 安全设置
- 删除操作前二次确认
- 敏感文件夹（系统目录）禁止操作
- 操作日志记录
```

## 使用指南

### 如何使用这些模板

1. **选择合适的模板**
   - 根据你的工作类型选择
   - 可以组合使用多个模板

2. **创建.claude文件**
   ```bash
   # 在工作区创建
   touch .claude
   # 或用编辑器创建
   ```

3. **粘贴模板内容**
   - 复制对应模板
   - 根据实际情况修改
   - 保存文件

4. **启动Claude Code**
   ```bash
   claude
   ```
   它会自动读取.claude文件

5. **验证配置**
   ```
   你好，请介绍一下你理解的项目配置
   ```

### 自定义技巧

1. **逐步完善**
   - 先用通用模板
   - 根据使用习惯逐步添加

2. **记录偏好**
   - 把反复强调的规则写进去
   - 记录常用的格式要求

3. **迭代优化**
   - 使用过程中发现问题
   - 及时更新.claude文件

4. **版本管理**
   - 重要配置可以备份
   - 用Git管理不同版本
