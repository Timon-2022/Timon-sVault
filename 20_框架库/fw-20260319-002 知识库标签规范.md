# **AI 笔记 YAML 规范（统一版）**

  

> 适用范围：

> 01_知识库 / AI

> 以及所有 **以 AI / 大模型 / Prompt / 协作为核心主题** 的笔记

---

## **一、设计目标（先说清楚）**

这套 YAML 规范只服务 **4 个目的**：

1. **快速判断这篇 AI 笔记“是什么”**
    
2. **区分：认知 / 方法 / 技巧 / 案例**
    
3. **支持长期检索与复用**
    
4. **避免随时间失效**
    

因此明确 **不追求**：

- ❌ 记录来源细节
    
- ❌ 跟目录重复分类
    
- ❌ 一篇笔记填满所有字段
    

---

## **二、AI 笔记统一 YAML 字段（标准集）**

  

> **这是“全集”**

> 实际使用时，只需选用其中一部分

```
---
类型: note            # note / case / principle / pattern
状态: evergreen       # evergreen / active / archived
领域:
  - AI
  - 大模型
主题: []              # AI协作 / 提示工程 / 模型理解 / 应用实践
层级: []              # 心智模型 / 方法论 / 技巧 / 反模式
用途: []              # 思考辅助 / 决策支持 / 创作辅助 / 学习理解
风险: []              # 幻觉 / 奉承 / 过度信任 / 误用
---
```

> ✅ 所有字段 **中文、稳定、可组合**

> ✅ 字段名 **永远不变**

> ✅ 值是「受控词表」，不是随便写

---

## **三、每个字段的**

## **严格定义**

## **（非常重要）**

### **1️⃣ 类型（必填）**

```
类型: note
```

|**类型**|**含义**|
|---|---|
|note|认知 / 总结 / 方法性笔记|
|principle|明确可复用的原则|
|pattern|Prompt / 使用模式|
|case|实战 / 应用 / 工作记录|

📌 **你的 AI 笔记 80% 应该是 note / principle**

---

### **2️⃣ 状态（必填）**

```
状态: evergreen
```

|**状态**|**含义**|
|---|---|
|evergreen|长期有效（默认）|
|active|正在打磨|
|archived|过时但保留|

📌 AI 方法论类内容，**大多应是 evergreen**

---

### **3️⃣ 领域（固定）**

```
领域:
  - AI
  - 大模型
```

📌 规则：

- AI 笔记 **一定包含** **AI**
    
- 是否加 大模型，取决于是否讨论 LLM 本身
    

---

### **4️⃣ 主题（最常用）**

```
主题:
  - AI协作
  - 提示工程
```

推荐受控词表（只从这里选）：

- AI协作
    
- 提示工程
    
- 模型理解
    
- 应用实践
    
- 工作流
    

  

📌 **主题 = 这篇笔记“在讨论 AI 的哪一块”**

---

### **5️⃣ 层级（决定价值高度）**

```
层级:
  - 心智模型
  - 方法论
```

|**层级**|**含义**|
|---|---|
|心智模型|如何理解 AI|
|方法论|行动原则|
|技巧|具体 Prompt|
|反模式|不该怎么用|

📌 **这是你区分“高手 / 技巧流”的关键字段**

---

### **6️⃣ 用途（连接现实）**

```
用途:
  - 思考辅助
  - 决策支持
```

推荐词表：

- 思考辅助
    
- 决策支持
    
- 创作辅助
    
- 学习理解
    

  

📌 用途 = **你什么时候会用到它**

---

### **7️⃣ 风险（高手字段）**

```
风险:
  - 奉承
```

推荐词表：

- 幻觉
    
- 奉承
    
- 过度信任
    
- 误用
    

  

📌 这是 **你未来 debug AI 的入口**

## **四、不同类型 AI 笔记的「标准 YAML 示例」**

  

### **✅ 示例 1：心智模型类（你刚那篇）**

```
---
类型: note
状态: evergreen
领域: [AI, 大模型]
主题: [AI协作, 提示工程]
层级: [心智模型, 方法论]
用途: [思考辅助, 决策支持]
风险: [奉承]
---
```

---

### **✅ 示例 2：Prompt 模式**

```
---
类型: pattern
状态: evergreen
领域: [AI]
主题: [提示工程]
层级: [技巧]
用途: [思考辅助]
风险: [幻觉]
---
```

---

### **✅ 示例 3：AI 实战案例**

```
---
类型: case
状态: active
领域: [AI]
主题: [应用实践]
用途: [工作执行]
关联原则:
  - Prompt 使用原则（模拟器视角）
---
```

## **五、你以后**

## **怎么判断一篇 AI 笔记该怎么打标签**

  

只问自己 **3 个问题**：

1. 这是 **理解 AI**，还是 **用 AI 干事**？
    
2. 这是 **原则**，还是 **技巧**？
    
3. 如果 AI 出问题，我希望 **从哪个风险维度找到它**？
    

  

能答出来，YAML 就不会乱。

---

## **六、最终建议（很关键）**

  

> **YAML 是“慢变量”，内容是“快变量”**

  

- YAML **半年改一次都嫌多**
    
- 内容可以天天变
    

  

你现在这套规范，**足够你用 2–3 年不动**。
