# Claude Code 新手快速上手清单

> 打印这个清单，跟着步骤做，30分钟内上手

## 📋 准备工作清单

### 第1步：检查电脑（5分钟）

- [ ] **操作系统**
  - [ ] Windows 10/11
  - [ ] macOS 10.15+
  - [ ] Linux (Ubuntu 20.04+)

- [ ] **网络**
  - [ ] 能访问 open.bigmodel.cn
  - [ ] 网络稳定

- [ ] **时间**
  - [ ] 预留30分钟 uninterrupted

---

## 📦 安装清单

### 第2步：安装Node.js（10分钟）

- [ ] 访问 https://nodejs.org
- [ ] 下载LTS版本（长期支持版）
- [ ] 一路点击"下一步"安装
- [ ] 打开终端/命令提示符
- [ ] 输入 `node -v` 检查
- [ ] 看到版本号（如v18.x.x）→ ✅ 完成

**遇到问题？** → 查阅《故障排查指南》"安装问题"部分

---

### 第3步：安装Claude Code（5分钟）

- [ ] 打开终端
  - [ ] Mac: Command + 空格，搜索"Terminal"
  - [ ] Windows: Win + R，输入"cmd"

- [ ] 复制粘贴以下命令：
  ```bash
  npm install -g @anthropic-ai/claude-code
  ```

- [ ] 等待安装完成（1-3分钟）

- [ ] 验证安装：
  ```bash
  claude --version
  ```

- [ ] 看到版本号 → ✅ 完成

**遇到问题？** → 使用一键安装脚本（配套资源中）

---

### 第4步：获取API密钥（5分钟）

- [ ] 访问 https://open.bigmodel.cn
- [ ] 注册/登录账号
- [ ] 进入"API Key"页面
- [ ] 点击"新建API Key"
- [ ] **复制API Key**（只显示一次！）
- [ ] 保存到记事本或密码管理器

---

### 第5步：购买套餐（推荐但可选）

- [ ] 登录智谱AI开放平台
- [ ] 进入"套餐购买"页面
- [ ] 选择"包季Coding Lite套餐"
- [ ] 支付54元
- [ ] 等待额度到账

**为什么购买？**
- 新用户有免费额度，但建议购买套餐
- 54元用3个月，每天0.6元
- 稳定可靠，不用担心用完

---

### 第6步：配置Claude Code（3分钟）

- [ ] 在终端运行：
  ```bash
  npx @anthropic-ai/claude-code-config-helper
  ```

- [ ] 按提示操作：
  - [ ] 选择"自定义API"
  - [ ] 粘贴API Key
  - [ ] 选择模型"glm-4-plus"（或"glm-4-air"）
  - [ ] 确认配置

- [ ] 看到"配置成功" → ✅ 完成

---

### 第7步：第一次启动（2分钟）

- [ ] 在终端输入：
  ```bash
  claude
  ```

- [ ] 看到启动界面 → ✅ 成功

- [ ] 输入测试：
  ```
  你好，请介绍一下你自己
  ```

- [ ] 收到Claude的回复 → ✅ 完全成功！

---

## 🎯 第一次实战清单

### 第8步：创建第一个工作区（2分钟）

- [ ] 在桌面创建文件夹："Claude Code工作区"
- [ ] 打开终端，进入这个文件夹：
  ```bash
  cd ~/Desktop/Claude\ Code工作区
  ```

- [ ] 在这个文件夹启动Claude Code：
  ```bash
  claude
  ```


- [ ] 等待执行

- [ ] 检查文件夹，确认文件已创建

- [ ] 输入：
  ```
  读取"测试.txt"文件的内容
  ```

- [ ] 看到文件内容 → ✅ 第一个任务完成！

---

### 第10步：尝试第二个任务（5分钟）

  ```
  2. 参会人员
  3. 讨论要点
  4. 决策事项
  5. 待办任务（负责人+截止日期）
  ```
