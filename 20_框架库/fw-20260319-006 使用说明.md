# 一键安装脚本使用说明

## 文件说明

本目录包含3个文件：
1. `Mac版.sh` - macOS和Linux安装脚本
2. `Windows版.ps1` - Windows安装脚本
3. `使用说明.md` - 本文件

---

## macOS / Linux 安装指南

### 方法1：直接下载运行（推荐）

```bash
# 下载脚本
curl -o install-claude-mac.sh https://your-repo/install-claude-mac.sh

# 赋予执行权限
chmod +x install-claude-mac.sh

# 运行脚本
./install-claude-mac.sh
```

### 方法2：在线运行

```bash
curl -fsSL https://your-repo/install-claude-mac.sh | bash
```

### 方法3：复制粘贴

1. 打开终端
2. 复制脚本内容
3. 粘贴到终端
4. 按回车执行

## Windows 安装指南

### 准备工作

1. 以管理员身份打开PowerShell
   - 按`Win + X`
   - 选择"Windows PowerShell(管理员)"

2. 允许运行脚本（首次使用）
   ```powershell
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
   ```

### 安装步骤

```powershell
# 切换到脚本所在目录
cd 你的路径\一键安装脚本

# 运行安装脚本
.\install-claude-windows.ps1
```

### 如果脚本被阻止

如果提示"无法加载文件，因为在此系统上禁止运行脚本"：

```powershell
# 临时允许运行
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

# 再次运行
.\install-claude-windows.ps1
```

## 安装后配置

安装完成后，需要配置API密钥才能使用：

### 1. 获取API密钥

1. 访问 [智谱AI开放平台](https://open.bigmodel.cn)
2. 注册/登录账号
3. 进入"API Key"页面
4. 点击"新建API Key"
5. **复制并保存这个Key**（只显示一次）

### 2. 购买套餐（推荐）

新用户有免费额度，但建议购买套餐：

- **包季Coding Lite套餐**：54元/3个月
- **跨年特惠**：关注活动页面

### 3. 配置Claude Code

在终端运行：
```bash
npx @anthropic-ai/claude-code-config-helper
```

按照提示：
1. 选择"自定义API"
2. 粘贴API Key
3. 选择模型"glm-4-plus"
4. 完成配置

### 4. 启动测试

```bash
claude
```

输入："你好，请介绍一下你自己"

## 常见问题

### Q1：Mac提示"无法验证开发者"

**解决方法**：
1. 打开"系统偏好设置" > "安全性与隐私"
2. 点击"仍要打开"
3. 或在终端运行：
   ```bash
   xattr -d com.apple.quarantine install-claude-mac.sh
   ```

### Q2：Windows提示SmartScreen警告

**解决方法**：
1. 点击"更多信息"
2. 点击"仍要运行"

### Q3：权限不足

**Mac/Linux**：
```bash
sudo npm install -g @anthropic-ai/claude-code
```

**Windows**：
以管理员身份运行PowerShell

### Q4：网络连接失败

**解决方法**：
配置国内镜像源：
```bash
npm config set registry https://registry.npmmirror.com
```

### Q5：Node.js安装后找不到命令

**解决方法**：
重启终端/电脑，使环境变量生效

## 卸载方法

### Mac/Linux

```bash
# 卸载Claude Code
npm uninstall -g @anthropic-ai/claude-code

# 删除配置文件（可选）
rm -rf ~/.claude
```

### Windows

```powershell
# 卸载Claude Code
npm uninstall -g @anthropic-ai/claude-code

# 删除配置文件夹（可选）
# 位置：C:\Users\你的用户名\.claude
```

## 手动安装

如果脚本安装失败，可以手动安装：

### Mac/Linux

```bash
# 1. 安装Node.js（如果未安装）
# macOS
brew install node@18

# Linux (Ubuntu/Debian)
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# 2. 配置npm镜像
npm config set registry https://registry.npmmirror.com

# 3. 安装Claude Code
npm install -g @anthropic-ai/claude-code

# 4. 验证安装
claude --version
```

### Windows

```powershell
# 1. 安装Node.js
# 访问 https://nodejs.org 下载LTS版本安装

# 2. 配置npm镜像
npm config set registry https://registry.npmmirror.com

# 3. 安装Claude Code
npm install -g @anthropic-ai/claude-code

# 4. 验证安装
claude --version
```
