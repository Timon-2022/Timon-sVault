## 安装问题

### 问题1：command not found: claude

**症状**：
```bash
$ claude --version
bash: claude: command not found
```

**原因**：
- npm全局安装路径不在PATH中
- 安装未成功

**解决方案**：

**方法1：检查安装**
```bash
# 查看npm全局安装路径
npm root -g

# 查看npm全局bin路径
npm bin -g
```

**方法2：添加到PATH**
```bash
# 临时添加（当前会话有效）
export PATH=$(npm bin -g):$PATH

# 永久添加（添加到 ~/.bashrc 或 ~/.zshrc）
echo 'export PATH=$(npm bin -g):$PATH' >> ~/.bashrc
source ~/.bashrc
```

**方法3：重新安装**
```bash
npm uninstall -g @anthropic-ai/claude-code
npm install -g @anthropic-ai/claude-code
```

**Windows特殊处理**：
```powershell
# 查看npm全局路径
npm root -g

# 手动添加到环境变量
# 路径通常在：C:\Users\你的用户名\AppData\Roaming\npm
```

---

### 问题2：npm install失败

**症状**：
```bash
$ npm install -g @anthropic-ai/claude-code
npm ERR! code ECONNREFUSED
npm ERR! errno ECONNREFUSED
```

**原因**：
- 网络连接问题
- npm registry访问不了

**解决方案**：

**方法1：配置国内镜像**
```bash
npm config set registry https://registry.npmmirror.com
npm install -g @anthropic-ai/claude-code
```

**方法2：清理缓存**
```bash
npm cache clean --force
npm install -g @anthropic-ai/claude-code
```

**方法3：使用代理**
```bash
npm config set proxy http://代理地址:端口
npm install -g @anthropic-ai/claude-code
```

---

### 问题3：权限不足

**症状**：
```bash
npm ERR! code EACCES
npm ERR! Error: EACCES: permission denied
```

**原因**：
- 没有写入全局目录的权限

**解决方案**：

**Mac/Linux**：
```bash
# 使用sudo
sudo npm install -g @anthropic-ai/claude-code

# 或修改npm全局目录（推荐）
mkdir ~/.npm-global
npm config set prefix '~/.npm-global'
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.bashrc
source ~/.bashrc
```

**Windows**：
以管理员身份运行PowerShell

---

### 问题4：Node.js版本过低

**症状**：
```bash
$ node -v
v16.20.0  # 版本低于18
```

**解决方案**：

**Mac**：
```bash
brew install node@18
brew link node@18 --force
```

**Linux (Ubuntu/Debian)**：
```bash
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs
```

**Windows**：
访问 https://nodejs.org 下载18+ LTS版本

## 配置问题

### 问题1：API Key无效

**症状**：
```
Error: Invalid API key
```

**原因**：
- API Key复制错误
- API Key已过期
- API Key格式不对

**解决方案**：

**检查API Key**：
1. 登录 [智谱AI开放平台](https://open.bigmodel.cn)
2. 查看API Key是否有效
3. 重新复制API Key

**重新配置**：
```bash
npx @anthropic-ai/claude-code-config-helper
```

---

### 问题2：模型调用失败

**症状**：
```
Error: Model not found: glm-4-plus
```

**原因**：
- 模型名称错误
- 套餐不包含该模型

**解决方案**：

**检查可用模型**：
- GLM-4-Plus（包季套餐）
- GLM-4-Air（免费额度）
- GLM-4-Flash（高速版）

**更换模型**：
```bash
npx @anthropic-ai/claude-code-config-helper
# 选择 glm-4-air 或其他可用模型
```

---

### 问题3：配置文件找不到

**症状**：
```
Error: Config file not found
```

**解决方案**：

**检查配置文件**：
```bash
# Mac/Linux
ls -la ~/.claude/

# Windows
dir C:\Users\你的用户名\.claude
```

**重新配置**：
```bash
rm -rf ~/.claude  # 删除旧配置
npx @anthropic-ai/claude-code-config-helper  # 重新配置
```

## 使用问题

### 问题1：Claude Code无响应

**症状**：
输入指令后长时间无反应

**原因**：
- 网络连接问题
- API限流
- 处理任务太大

**解决方案**：

**检查网络**：
```bash
ping open.bigmodel.cn
```

**查看日志**：
```bash
claude --debug
```

**简化任务**：
- 分步骤执行
- 减少单次处理的数据量

---

### 问题2：文件操作权限被拒

**症状**：
```
Error: Permission denied: /path/to/file
```

**原因**：
- 没有文件读写权限
- 文件被占用

**解决方案**：

**检查权限**：
```bash
ls -l 文件路径
```

**修改权限**：
```bash
# Mac/Linux
chmod 644 文件路径

# Windows
# 右键文件 → 属性 → 安全 → 编辑权限
```

**关闭占用程序**：
- 确保文件没被其他程序打开

---

### 问题3：内存不足

**症状**：
```
Error: JavaScript heap out of memory
```

**原因**：
- 处理文件太大
- Node.js默认内存限制

**解决方案**：

**增加Node.js内存**：
```bash
export NODE_OPTIONS="--max-old-space-size=4096"
claude
```

**分批处理**：
- 不要一次性处理超大文件
- 分批读取和处理

---

### 问题4：输出中文乱码

**症状**：
中文显示为问号或乱码

**解决方案**：

**Mac/Linux**：
```bash
export LANG=zh_CN.UTF-8
export LC_ALL=zh_CN.UTF-8
claude
```

**Windows**：
```powershell
# 设置终端编码为UTF-8
chcp 65001
claude
```

## 性能问题

### 问题1：响应速度慢

**可能原因**：
- 网络延迟
- API服务器负载高
- 模型选择不当

**解决方案**：

**更换模型**：
- GLM-4-Flash：响应最快
- GLM-4-Air：速度与质量平衡
- GLM-4-Plus：质量最好但稍慢

**优化网络**：
- 使用稳定的网络环境
- 配置代理（如需要）

---

### 问题2：Token消耗过快

**症状**：
额度用得很快

**原因**：
- 处理大文件
- 长对话上下文
- 频繁重试

**解决方案**：

**优化指令**：
- 指令更简洁明确
- 避免重复读取大文件

**定期清理上下文**：
```bash
/clear  # 清空对话历史
```

**使用.claude文件**：
- 预设规则，减少重复说明

---

### 问题3：频繁断线重连

**症状**：
经常提示连接失败

**原因**：
- 网络不稳定
- API服务器问题

**解决方案**：

**检查网络**：
- 确保网络稳定
- 尝试切换网络（WiFi/有线）

**使用代理**：
```bash
export HTTP_PROXY=http://代理地址:端口
export HTTPS_PROXY=http://代理地址:端口
claude
```
