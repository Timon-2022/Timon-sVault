# Claude Code 常用指令速查表

> 打印出来，贴在电脑旁，随时查阅

## 基础操作

### 启动与退出
```bash
# 启动 Claude Code
claude

# 退出（方法1）
/exit

# 退出（方法2）
Ctrl + D

# 清除历史上下文
/clear
```

### 版本与帮助
```bash
# 查看版本
claude --version

# 查看帮助
claude --help
```

## 注意事项

⚠️ **重要提醒**：
1. 首次使用在独立文件夹测试
2. 重要文件先备份
3. 指令越具体，结果越准确
4. 不确定时让它先"别执行，先告诉我怎么做"
5. 开启危险模式前务必了解后果

💡 **使用技巧**：
- 用自然语言描述需求，不用管语法
- 分步骤指令比一步到位更可靠
- 遇到错误让Claude自己修复
- 善用"角色设定"提升输出质量
