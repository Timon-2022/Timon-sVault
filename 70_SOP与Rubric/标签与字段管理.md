**「在 Obsidian 中可执行、可约束、可对接 Notion」的标签管理法则**。

---

# **一、Obsidian 标签的总原则（先记住这 4 句）**


> **1️⃣ 标签不是分类，是“视角”**

> **2️⃣ 标签必须可复用，不能一次性**

> **3️⃣ 能用字段（YAML）解决的，不用自由标签**

> **4️⃣ 标签结构必须“有限 + 约束”**

如果你只记住这一段，已经能避免 80% 的坑。

---

# **二、你在 Obsidian 中「只允许存在 4 类标签」**

⚠️ **这是硬规则，不要加第五类**

```
主题（topic）
项目（project）
状态（status）
来源（source）
```

👉 所有标签，都必须属于这 4 类之一
👉 并且 **用前缀强制区分**

---

# **三、推荐你的「标签命名规范」（直接照抄）**

## **✅ 统一格式（非常重要）**

```
类别/具体值
```

### **示例**

```
主题/AI商业模式
项目/博商
状态/进行中
来源/书籍
```

📌 **不允许**

- AI商业模式（无前缀）
    
- 博商项目（混合语义）
    
- #todo #idea（不受控）
    

---

# **四、四大类标签的「使用法则 + 示例」**

  

下面这部分是**你每天真的会用到的**。

---

## **① 主题标签（你在研究什么）**

  

### **使用原则**

- **长期稳定**
    
- 数量少（10–20 个以内）
    
- 不轻易新增
    

  

### **示例（结合你实际场景）**

```
主题/AI商业模式
主题/AI财务
主题/内容创作
主题/智能体
主题/个人IP
```

### **在 YAML 中的写法**

```
tags:
  - 主题/AI商业模式
```

📌 **主题标签 ≠ 目录**

- 不负责“放哪”
    
- 只负责“关于什么”
    

---

## **② 项目标签（为谁而写）**

  

### **使用原则**

- 一个笔记 **最多 1 个项目标签**
    
- 项目结束后，不再新增
    

  

### **示例**

```
项目/博商
项目/创业
项目/小红书
```

📌 如果你已经在 YAML 里用：

```
project: 博商
```

那**标签里可以不再写 项目/博商**

（字段 > 标签，字段更干净）

  

👉 **优先用字段，标签做补充**

---

## **③ 状态标签（现在到哪一步）**

  

### **使用原则**

- **强烈建议用 YAML 字段，而不是标签**
    
- 如果你习惯标签，也必须受控
    

  

### **推荐状态集（不要扩展）**

```
状态/想法
状态/进行中
状态/可输出
状态/已同步
状态/已归档
```

### **YAML 写法（推荐）**

```
status: 进行中
```

📌 **状态是会变的，不适合自由标签**

---

## **④ 来源标签（从哪来的）**

  

### **使用原则**

- 可选
    
- 用于回溯信息可信度
    

  

### **示例**

```
来源/书籍
来源/课程
来源/会议
来源/实践
```

---

# **五、强烈推荐：用「YAML 字段」替代 60% 的标签**

  

你现在的系统里，**标签不是主角，字段才是**。

  

## **✅ 推荐的 Obsidian 标准 YAML（你可以设成模板）**

```
type: note
project: 创业
channel: 小红书
topic: AI商业模式
status: 观察
source: 实践
```

👉 那标签区只保留 **1–2 个主题标签即可**。

---

# **六、你以后「新建一条笔记」时的标准动作（30 秒）**

  

照着做，不思考：

  

1️⃣ 选目录（工作 / 创业 / 灵感）

2️⃣ 写 YAML（5 行以内）

3️⃣ 主题标签最多 1–2 个

4️⃣ 不纠结，不美化

---

# **七、标签「禁止事项清单」（非常重要）**

  

❌ 不允许：

- 同义标签（AI / 人工智能）
    
- 情绪标签（重要 / 紧急）
    
- 临时标签（#看看 #有用）
    

  

❌ 不允许：

- 把任务当标签（#todo）
    
- 把结论当标签（#好方法）
    

  

👉 这些 **全部用正文或字段**

---

# **八、标签生命周期管理（避免越用越乱）**

  

### **每月一次（5 分钟就够）**

- 打开标签面板
    
- 看有没有：
    
    - 用过 1 次的标签
        
    - 意义不清的标签
        
    
- 合并 / 删除
    

  

📌 **标签应该越来越少，而不是越来越多**

---

# **九、Obsidian ⇄ Notion 的「对齐规则」（关键）**

|**Obsidian**|**Notion**|
|---|---|
|topic / tags|主题|
|project|项目|
|status|状态|
|channel|渠道|

👉 **字段对齐 > 标签对齐**

👉 标签只是“辅助视角”
