# 公众号撰文要点规则

> 核心洞察：公众号的第一性原理是**情绪**

## 基本原理

### 1. 流量逻辑原理

**公众号的本质是半私域**
- 不是纯流量平台（不像抖音、小红书靠推荐）
- 需要从其他渠道引流 → 公众号做内容交付
- 公众号是信任沉淀和深度互动的场所

**流量漏斗**：
```
公域平台（抖音/小红书/知乎）
    ↓ 吸引关注
公众号（深度内容）
    ↓ 信任沉淀
铁粉（流量杠杆）
    ↓ 撬动系统推荐
更大曝光
```

### 2. 算法推荐原理

**公众号推荐机制的关键**：
- 系统会根据文章打开率、完读率、转发率判断质量
- **铁粉的互动是撬动系统推荐的关键杠杆**
- 如果推出去后只有10%的人感兴趣，系统会降低推荐
- **铁粉用来撬动整个流量奖励**

**垂直度的价值**：
- 垂直内容吸引精准粉丝
- 精准粉丝互动率更高
- 高互动率触发更多推荐
- 形成正循环

### 3. 内容策略原理

**为什么半原创优于纯原创**：

**纯原创的问题**：
- 太前沿，读者无法建立认知链接
- 曲高和寡，难以产生共鸣
- 缺乏社交货币价值（无法和朋友讨论）

**半原创的优势**：
- 基于大家都了解的领域做解读
- 读者有基础认知，更容易建立连接
- 提供"新角度"而非"全新事物"
- 具备社交货币属性（可以转发给朋友讨论）

**公式**：半原创 = 大众已知话题 × 独特视角 × 情绪价值

## 撰文原则

### 原则1：情绪优先原则

**核心**：所有内容必须触发某种情绪

**三大情绪触发点**：

#### A. 有用（干货型）
- **本质**：教人一招，节省时间/金钱
- **表现**：
  - "看完就能用"
  - "省了X小时"
  - "避坑指南"
- **例子**：
  - "Claude Code保姆级教程：29秒拆分工资条"
  - "月薪3k到AI自由：低成本工具箱"
  - "5个Excel技巧，加班少2小时"

#### B. 有趣（娱乐型）
- **本质**：让人开心，放松解压
- **表现**：
  - 幽默的表达
  - 反转的剧情
  - 轻松的语调
- **例子**：
  - "我被AI裁员的第3天"
  - "当产品经理用ChatGPT写周报"
  - "技术人vs非技术人：同一个世界不同的梦"

#### C. 共鸣（情感型）
- **本质**：说出心声，感觉"你懂我"
- **表现**：
  - "这说的就是我"
  - "终于有人说出来了"
  - "转发给老板/同事/朋友看"
- **例子**：
  - "为什么你的AI培训听了很多课还是不会用"
  - "企业AI落地踩过的7个坑"
  - "技术人的中年危机：从写代码到做选择"

**情绪叠加公式**：
```
最佳内容 = 有用 + 有趣 + 共鸣
优秀内容 = 有用 + 共鸣
合格内容 = 至少触发一个情绪
```

---

### 原则2：垂直聚焦原则

**一个内容一个号是流量最优选择**

**为什么**：
1. 算法需要明确标签
2. 粉丝知道关注你是为了什么
3. 便于形成系列化内容
4. 铁粉更容易沉淀

**如何垂直**：
- **主题垂直**：AI工具使用、企业培训、产品经理
- **人群垂直**：职场新人、技术人、创业者
- **场景垂直**：办公效率、数据分析、内容创作

**垂直度自检**：
```
问自己：这篇文章发出去，读者能记住我"擅长什么"吗？
- 如果能 → 垂直度OK
- 如果不能 → 需要调整
```

---

### 原则3：稳定输出原则

**日更的核心目的**：
- 不是每篇都要爆款
- 而是让别人知道你还活着
- 保持账号活跃度
- 维持用户习惯

**更新节奏建议**：
- **日更**：保持存在感，适合增长期
- **周3更**：质量优先，适合稳定期
- **周2更**：最低频率，再少就凉了

**日更的可行性**：
- 不是每篇都要深度长文
- 可以"长短结合"
- 预备稿库应对突发情况

**内容配比建议**：
```
60% 稳定输出型（常规干货）
30% 爆款尝试型（情绪强触发）
10% 个人品牌型（建立信任）
```

---

### 原则4：小爆款优先原则

**稳定的小爆款 > 随机的大爆款**

**为什么**：
- 小爆款可复制
- 大爆款靠运气
- 稳定才能持续增长
- 变现能力更强

**小爆款定义**：
- 阅读量：日常的2-3倍
- 转发率：15%+
- 收藏率：20%+
- 虽不是刷屏级，但稳定出现

**大爆款的问题**：
- 不可预测
- 难以复制
- 粉丝不精准
- 后续内容压力大

**打造小爆款方法论**：
1. **选题验证**：用小标题在朋友圈测试反应
2. **情绪触发**：至少包含"有用+共鸣"
3. **标题优化**：参考同类爆款标题结构
4. **发布时间**：固定时间发布，培养习惯
5. **数据复盘**：分析为什么这篇数据好

---

### 原则5：半原创创作原则

**半原创的本质**：在大众认知基础上，提供独特视角

**半原创三要素**：

#### 1. 大众已知话题
- ✅ 选择热门领域（AI、职场、效率）
- ✅ 大家都听说过但不深入了解
- ❌ 不要完全冷门的新概念
- ❌ 不要过于前沿的技术

**例子**：
- ❌ "Transformer架构的数学推导"（太前沿）
- ✅ "提示词工程的5层金字塔"（听说过但不会用）
- ✅ "飞书多维表格+AI：一个人活成一支队伍"（工具+场景）

#### 2. 独特视角
- 你的专业背景
- 你的真实经历
- 你的实战案例
- 你的思考框架

**视角来源**：
- **企业培训AI产品经理** → 企业AI落地、培训方法论
- **金融投研背景** → AI辅助分析、数据处理
- **个人踩坑经历** → 避坑指南、经验总结

#### 3. 情绪价值
- 不只是讲道理
- 要触发情绪（有用/有趣/共鸣）
- 用故事承载信息
- 用金句传播观点

**半原创创作公式**：
```
热门话题 + 专业视角 + 情绪包装 = 半原创爆款

例1：
热门话题：Claude Code
专业视角：非程序员也能用
情绪包装：54元换来24小时AI员工

例2：
热门话题：AI提示词
专业视角：5层金字塔框架
情绪包装：从懵逼到灵魂伴侣

例3：
热门话题：AI培训
专业视角：培训失效的根本原因
情绪包装：听完激动，回到工位不会动
```

## 实操要点

### 标题设计原则

**功能**：标题不是描述内容，而是触发情绪

**标题公式库**：

#### 1. 数字+利益点
```
"5个XX技巧，省X小时"
"10个选题，带你从0到1"
"3个原则，让你的XX翻倍"
```

#### 2. 对比+反转
```
"月薪3k到AI自由"
"听完激动，回到工位不会动"
"技术公众号基本都停更了"
```

#### 3. 场景+解决方案
```
"29秒搞定繁琐工作"
"一个人活成一支队伍"
"用54元换来24小时AI员工"
```

#### 4. 身份标签+共鸣
```
"写给非程序员的Claude Code教程"
"企业AI产品经理的生存指南"
"为什么你的AI培训听了很多课还是不会用"

#### 5. 负面情绪+解决方案
```
"踩过的7个坑，80%的公司都在重复"
"揭秘：为什么XX总是失败"
"告别XX焦虑"
```

**标题自测**：
- [ ] 是否包含数字？（具体感）
- [ ] 是否触发情绪？（有用/有趣/共鸣）
- [ ] 是否明确受众？（让对的人点进来）
- [ ] 是否有利益点？（读了能得到什么）

---

### 开头设计原则

**开头三要素**：

#### 1. 痛点场景（前100字）
**目的**：让读者说"这就是我！"

**公式**：具体场景 + 痛苦感受
```
❌ 差：很多人工作效率低

✅ 好：
每天处理200个客户信息，Excel表格看得眼睛发酸
拆分工资条要花2小时，重复到想吐
会议纪要整理完，已经没有精力做其他事了
一天4小时被机械性工作占满
```

#### 2. 共鸣声明（接下来200字）
**目的**：让读者知道"我理解你"

**公式**：我也是 + 现状描述 + 转折点
```
两个月前，我也是这样。

直到我发现了Claude Code，
不是什么高大上的技术，
而是一个能直接操作我电脑的AI助手。
```

#### 3. 价值承诺（再接下来100字）
**目的**：让读者觉得"这篇文章对我有用"

**公式**：这篇文章能帮你 + 具体收益
```
这篇教程写给所有不会编程、但想用AI提升效率的普通人。
我会手把手教你：
- 10分钟完成安装
- 5个实用场景演示
- 29秒搞定原本2小时的工作
```

### 结构设计原则

**文章结构公式**：

```
开头（400字）
├─ 痛点场景：让读者说"这就是我"
├─ 共鸣声明：让读者觉得"你懂我"
└─ 价值承诺：让读者知道"能学到什么"

主体（60%篇幅）
├─ 分点论述（3-5个点）
├─ 每个点包含：
│   ├─ 小标题（金句化）
│   ├─ 问题/场景
│   ├─ 方法/案例
│   └─ 金句总结
└─ 用"第一""第二"或"01""02"编号

结尾（400字）
├─ 总结全文（提炼3个要点）
├─ 行动建议（看完后做什么）
├─ 情绪升华（给读者希望）
└─ 引导互动（点赞/转发/关注）
```

---

### 金句设计原则

**金句的作用**：
- 便于转发（一句话说清观点）
- 便于记忆（浓缩核心价值）
- 便于传播（有传播性）

**金句公式**：

#### 1. 对比式
```
"不是XX，而是XX"
- Claude Code不是工具，而是伙伴
- 不是提问，而是协同思考
```

#### 2. 数字式
```
"X小时 → X分钟"
- 2小时 → 29秒
- 每天4小时 → 每天10分钟
```

#### 3. 比喻式
```
"XX就像YY"
- AI就像最强大的实习生
- 提示词就像和AI沟通的语言
```

#### 4. 否定式
```
"不要XX，要XX"
- 不要追求完美，要追求进步
- 不要一次性培训，要持续陪伴
```

#### 5. 行动式
```
"从XX到XX"
- 从ChatGPT懵逼到AI灵魂伴侣
- 从月薪3k到AI自由
```

## 禁忌清单

### ❌ 不要做的事

1. **不要纯原创**
   - 太前沿读者无法建立链接
   - 用半原创：大众话题 + 独特视角

2. **不要追求大爆款**
   - 大爆款靠运气
   - 追求稳定的小爆款

3. **不要不垂直**
   - 今天写技术，明天写情感
   - 一个内容一个号

4. **不要断更**
   - 日更保持活跃
   - 让别人知道你还活着

5. **不要只讲道理**
   - 要有情绪价值
   - 用故事承载信息

6. **不要忽视标题**
   - 标题决定打开率
   - 花50%时间打磨标题

7. **不要忘了铁粉**
   - 铁粉是流量杠杆
   - 写他们关心的内容

## 最后的忠告

**公众号的第一性原理是情绪**，不是信息。

技术内容是情绪的载体，不是目的。

**记住**：
- 读者不缺信息，缺的是情绪价值
- 公众号不是技术文档，是情绪共鸣场
- 铁粉关注你，不是因为你技术多牛，而是因为"你懂我"

**写完每篇文章后问自己**：
1. 这篇文章触发情绪了吗？
2. 读者转发时配什么话？
3. 读者看完后会对谁说"这篇文章写得真好"？

如果三个问题都有答案，那就发吧。
