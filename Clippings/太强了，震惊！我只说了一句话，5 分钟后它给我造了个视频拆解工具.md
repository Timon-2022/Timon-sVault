## 传统开发方式的三个痛点

![图像](https://pbs.twimg.com/media/HD0qJuHboAALRIK?format=jpg&name=large)

你有没有遇到过这种情况：

想做个视频拆解工具，得先学 ffmpeg，再写 Python 脚本，调试半天，最后还得配置环境。

一个简单的需求，要折腾 1-2 小时。

**痛点 1：手动开发太慢**

- 写代码 → 调试 → 部署 → 维护
- 一个简单的视频拆解工具，至少要 2-3 天

**痛点 2：预制 Skill 不够灵活**

- Skill 是预制菜，只能覆盖通用场景
- 遇到定制需求，要么改代码，要么放弃

**痛点 3：一次性对话不可复用**

- 每次都要重新描述需求
- 没有记忆，没有积累

## 与 Skill 系统的区别

![图像](https://pbs.twimg.com/media/HD0sL2Ra8AAsEvK?format=jpg&name=large)

**Skill 的做法（MCP、OpenClaw Skill、Cursor Rules）：** 

- 开发者手动写好 Skill
- 用户调用现成的 Skill
- 适合通用场景（天气查询、文件操作）

**Creao 的做法：**

- AI 根据你的需求现场生成 Skill
- 每个 Agent App 都是定制的
- 适合一次性场景（视频拆解、数据分析）

![图像](https://pbs.twimg.com/media/HD0sUNkboAEXctx?format=jpg&name=large)

**举个例子：**

- Skill：你去餐厅点"宫保鸡丁"，厨师按标准菜谱做
- Creao：你告诉厨师"我想吃辣一点的鸡丁，加点花生"，厨师现场调整

**两者不冲突：**

- 通用需求用 Skill（比如"读取 Twitter 推文"）
- 定制需求用 Creao（比如"拆解抖音视频 + 生成 AI 提示词"）
